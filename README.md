# Surplus Food Rescue Network

A web platform that connects people with surplus food to those who need it, with a simple way to order, donate, or volunteer.

🔗 **Live demo:** https://your-project.vercel.app
🎥 **Demo video:** (paste video link)

## The Problem
Large amounts of edible food go to waste every day while people nearby go hungry. This project makes it easier to connect the two.

## Features
- **Order:** request available surplus food
- **Donate:** list food you want to give away
- **Volunteer:** sign up to help with pickup and delivery
